# ChatGPTによる教材作成・端末内学習

ChatGPTがこのチャットで作成した39例を使用しました。24例を学習、6例をエポック選択、9例を評価に隔離し、既存教材と併せて候補ランキングモデルを学習しています。24学習例は6分野各4例です。教師はQwenではありません。ChatGPT自身の重みは変更しません。

再現コマンド: `python models/chatgpt-training/run-training.py`。成果物は `.cache/chatgpt-training/session-20261012/`、結果は `benchmarks/results/chatgpt-training.json`。

今回の新規評価用文章は候補比較で2/9から5/9になりました。一方、既存評価は6/6から4/6に低下しました。今回のモデルはIME適用不採用として保管しています。評価に正解候補を与える測定であり、ローマ字からの変換全体の精度ではありません。教材はChatGPTによる合成例で、独立した人間の正解確認はありません。語彙の系列は学習・評価にまたがるため、未知分野全般での性能を示しません。

Qwenの常駐学習・自動起動・監視は停止しました。入力履歴は使わず、学習処理は端末内で実行しました。稼働中IMEは今回のモデルに切り替えていません。

教材と実行スクリプト: AGPL-3.0-only。
