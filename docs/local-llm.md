# 端末内の文章理解AI

最新のケース選択仕様は [AIによる大文字・小文字の選択](automatic-casing.md) を参照してください。以下のケース固定に関する説明は、その機能を追加する前の記録です。

2026-10-11、ユーザーの「端末内で動くAI」という選択に基づき、Qwen3-4Bの量子化モデルとllama.cppを接続しました。既存の文字統計モデルとは別のニューラル言語モデルです。今回追加したのは文脈を使う候補の順位づけで、文章生成・返信の自動送信・モデルの追加学習ではありません。

「あい」「ai」は変換・候補選択でAIを第一候補にする設定に変更しました。未確定の読みを勝手に確定しません。「愛を伝える」「愛する」「愛を込めて」の読みは専用の辞書候補に残しています。「あい」をすべての文脈でAIへ固定する機能ではありません。

「あいが」「あいを」など助詞付き入力と「えーあい」も登録しました。「あい」の候補には「愛」も残しています。

## 動作

確定した直前の96文字、今回の読み、既存候補のうち最大12件を、端末内の専用プロセスに渡します。読みそのままの候補はモデルへの選択肢から除外しますが、IMEの候補には維持します。モデルは候補番号だけを返し、辞書にない文章を挿入できません。

Spaceで通常候補を先に表示します。モデルの計算は別プロセス、応答の受け取りは100msごとのホストタイマーで行います。通信の転送は非同期ソケットです。ループバックへの初回接続には上限10msの接続処理があり、通常変換イベントでは実行しません。応答受信は2秒で打ち切り、モデル推論は最大30秒で打ち切って通常候補に戻ります。入力・候補移動・確定・取消・文脈消去・AI無効化があれば古い結果は適用しません。F9で軽量AIと文章理解AIを無効にできます。

候補ウィンドウに「文章理解AI:端末内 / 処理中」または「有効」を表示します。「有効」は接続設定があることを示し、サーバーが停止している場合は通常候補で継続します。実アプリでの物理キー到達と描画の検証は、今回のTSFホストテストに含まれません。

## プライバシーと起動

モデルの取得にはインターネットを使います。推論時は固定の `127.0.0.1:43820` と `127.0.0.1:43821` のみを使用し、プロキシとDNSを使いません。64桁のランダムな認証トークンを要求します。入力・候補・文脈をログに保存せず、ジョブはメモリ内で最大64件・60秒保持します。処理待ちキューは1件です。パスワードと宣言された入力欄はWindowsアダプターで対象外になりますが、正しい入力スコープを宣言しないアプリの識別は保証できません。他アプリの履歴を読み出しません。

```powershell
python scripts/setup-local-ai.py
./scripts/start-local-ai.ps1
./scripts/stop-local-ai.ps1
```

設定は `%LOCALAPPDATA%/Luqnexa/local-ai.json`、モデルとランタイムは `.cache/local-ai` に保存します。起動時にモデルのSHA-256を再検証します。IME側はセッション作成時、新しい入力の開始時、通常候補への変換時、F9で有効にした時に設定を読み直すため、ヘルパーの遅い起動や認証トークン更新にも対応します。毎文字・タイマーごとの設定ファイル読み込みは行いません。F9でユーザーが無効化した設定は勝手に有効化しません。

Windowsでは設定を `HKCU/Software/Luqnexa/LocalAI` に複製します。ブラウザー内のIMEで設定ファイルが未検出になる場合に限り、保存先の一致する複製を読みます。ファイルでの無効設定やJSON形式エラーは優先されます。複製にも認証キーが含まれるため公開・ログ出力の対象外です。停止スクリプトとヘルパーの正常終了で複製を削除します。無効化にはF9または停止スクリプトを使用してください。Windowsの設定テストは子プロセスのHKCUだけを一時キーへ切り替え、実ユーザーの設定を変更せず6ケースを検証します。

`./scripts/start-local-ai.ps1 -RegisterStartup` は現在のユーザーのWindowsログイン時の起動を登録します。`stop-local-ai.ps1` はその起動登録を解除し、端末内ヘルパーを停止します。2026-10-12、この端末で自動起動を登録しました。古いDLLを読み込み済みのアプリはIME更新後に開き直す必要があります。iOS等でこのランタイムを検証したわけではありません。

公式の [Qwen3-4B-GGUF](https://huggingface.co/Qwen/Qwen3-4B-GGUF) の `Q4_K_M`、commit `bc640142c66e1fdd12af0bd68f40445458f3869b` を使用します。ファイルは2,497,280,256バイト、SHA-256は `7485fe6f11af29433bc51cab58009521f205840f5b4ae3a32fa7f92e8534fdf5`。モデルのApache-2.0ライセンスを `.cache/local-ai/QWEN-LICENSE.txt` に保持します。

[llama.cpp](https://github.com/ggml-org/llama.cpp) のWindows CPU x64版 `b11554` を使用します。公式リリースのZIPはSHA-256 `927850725a5fb8a6b453891b324c4f2d4be17905f7c5b9a265f8f73daa3bd39d` と照合して展開します。MITライセンスで、取得元は `.cache/local-ai/manifest.json` に記録します。これらの第三者成果物をAGPLへ変更しません。Rust側のJSON解析にはserde_json 1.0.140を使用します。
