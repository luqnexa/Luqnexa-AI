# 実変換の誤候補を点検して追加した学習

2026-10-13。活用語形の別辞書を併用し、93例の学習へ進めました。元の86訓練例を実辞書で変換し、正解が候補内にあるのに第一候補が異なる20対比を点検しました。何処／どこ、気付く／気づく、機会・機械／きかいの四例は意味の誤りではないため追加対象外です。既存の対比と同じ九例は重複として追加しません。

新規は実際の誤候補七対比で、七つの新しい文章ではありません。newsの否定形、passwordの変更、serverの移行、YouTubeの表記、USB接続の反応、二つの文脈のmailの回答を扱います。全文の登録ではなく候補比較の訓練です。固定validation/testの内容は維持し、勾配計算は訓練だけに使います。自己点検であり独立した人間の確認ではありません。

93対比でinteraction-v2・shuffled・seed1337・2,000epochを独立二度実行しました。validation8/12、test12/24で、旧研究モデルより退行したため不採用です。SHA-256は5ea73dfb74bcbb4c9c04791e500b07d833fbc0aa1364ee33934ed57a8588e31cで一致しました。

訓練への過度の適合を抑える実験としてRust学習器にepochごとの重み減衰を追加しました。既定は0で、過去の学習を変更しません。有限の0～0.1だけを受け付け、バイアスを除く重みへ一度適用します。0でバイト列が変わらないこと、不正値でモデルを変えないことをテストしています。推論形式や実行コストは変更しません。

減衰0.001の一条件を同じ訓練で独立二度実行しました。validation8/12、test12/24で改善せず、不採用です。SHA-256は62d1492cb8b23004e1d53d4e3b90bb83ce19f79b3589fcc49075b9c1bf0b63a3で一致しました。固定評価の個別解答に合わせた教材や減衰値の探索はしていません。結果は正解候補を与えた比較であり、IME全体・誤字補正・iPhone実測ではありません。
