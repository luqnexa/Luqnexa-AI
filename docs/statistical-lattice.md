# 品詞接続の統計モデルを使う隔離実験

2026-10-13。順位モデルの学習だけでは正解が候補に入らないため、`nextime-convert::statistical` に別の候補生成経路を作りました。既定のEngine・Session・稼働IMEは変更しません。自作Rustコードが辞書の左・右品詞ID、単語コスト、文頭・文末の接続コストを使い、各位置で最大128経路を保持します。最大32候補・入力128文字です。限定ビーム探索であり、全経路を網羅した最適解を保証しません。

接続コストは独自モデルが今回学習したものではなく、Mozcの公開辞書データです。固定revisionは `18e76511af9371a9a4409b1d13c3e30884b53e9c`。取得スクリプトはSHA-256 `68823a1f6617372ccb89afdbcb334d7a0bcfa82c9c5dda03fc1f80f1cab5c48e` と本リポジトリの品詞定義のSHA-256 `07a05a268c3783b7e02b36e4aa591555a2dd19a1f3c93891576740761c154f2d` を照合し、不一致や既存ファイルへの上書きを拒否します。ソースは https://github.com/google/mozc/blob/18e76511af9371a9a4409b1d13c3e30884b53e9c/src/data/dictionary_oss/connection_single_column.txt 。第三者の著作権・BSD条件は `dictionaries/MOZC-NOTICES.txt` を保持します。Mozcの検索・圧縮エンジンは組み込みません。

入力ファイルは先頭が次元、以後は前単語の右ID×次単語の左IDの行列です。2672×2672のsigned16bitとして14,279,168 bytesを保持する診断実装です。スマホ向け軽量形式ではありません。読み込み時間は変換p95の外側です。未知文字は保持し、ASCII列はまとまりとして残します。非Mozc辞書語の接続IDは一般名詞への近似です。派生活用語のIDは元辞書語を引き継ぐため、実際の活用後IDとは異なる場合があります。接続データのバージョン整合性は呼び出し側が確認します。

Windows x86_64、実辞書47,526,644 bytes、実験用追記辞書、362,055語形の別辞書、研究モデル `4463b9786d624d86486d82d4b2206a39499ed2e893306453d5cd6ee55b447ffd` を使用しました。各文10回のウォーム測定で、キーごとの入力、iPhone、電力、1億エントリではありません。参照解答を検索へ渡していません。

validationは新しく正解した4件と退行した1件があります。繰り返し利用している小さな固定評価であり、独立した未知文の一般精度ではありません。90%・5msは未達です。実験経路と成果物は保存するだけで、稼働IMEへ適用しません。

新経路で現れた訓練の誤候補30件を一件ずつ点検し、かな／漢字など許容可能な表記と大文字の根拠が弱い5件、既存の対比12件を除外し、13対比を追加しました。新しい文章13件ではありません。音楽、天気、表計算、ハードウェア、書籍、工作、地域の放送などの場面で、累積106対比です。自己点検を人間による独立確認とは呼びません。

同じ固定validation/testと明示seed1337を保持し、interaction-v2・shuffled・2,000epoch・減衰0で独立2回学習しました。モデル選択はvalidationのみです。量子化モデルのSHA-256は両方 `10e6fd72ca5ba752b34d80c503b96fbbe03e3fccef0a76c9cf50963f3a0bedc1`。候補ペア評価はtrain91/106、validation8/12、test17/24で、旧研究モデルのvalidation10/12を下回るため不採用です。固定評価の文章を訓練へ移していません。
