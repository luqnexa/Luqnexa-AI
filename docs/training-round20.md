# 同じ読み・異なる文脈の対比学習

2026-10-13。第20教材群は日英混在の12入力に、それぞれ意味の異なる二つの文脈と逆向きの正解を与えた24例です。12入力・24例を24種類の新しい入力とは数えません。人工知能／愛情、橋／食事の道具、天気／菓子、チャンス／装置、文字／印象等を異なる場面で扱います。ローマ字、文法、英語保持、意味を自己点検しましたが、独立した人間の正解確認ではありません。

旧48文と累積して訓練72例・60入力にしました。固定validation12文とtest24文は変更せず、正規化した評価内容のSHA-256 `d8257f1acc8919572425c20a78691be7cf5e256e4a6bdc2585f1618f5416be14` を照合しました。旧モデル・教材・辞書を保持し、seed1337のゼロ初期化を使います。モデル選択は量子化後のvalidationのみです。

200epochを独立二度実行した結果はvalidation7/12・test11/24で、不採用です。200epochで文脈を学べていない記録から、短い独立した対比テストを追加しました。同じ読みの`utensil`と`bridge`を`meal`と`river`で逆に選べることを2,000回の学習後に確認しています。短い対比の能力を、一般的な文脈理解と呼びません。

同じ累積教材で2,000epochの研究runを独立二度実行しました。SHA-256は `834d0b46bf81dc7fc67d156f74a1a7061a99f1730e2967aca8a428efd9442bf5` で一致しました。validationで選ばれた1949epochの候補は訓練60/72・validation8/12・test14/24です。元モデルのvalidation9/12・test17/24より低いため不採用にし、稼働IMEに適用しません。testの正解を訓練に移動していません。

新しいRustの`pair-audit`で第20教材群だけを読み取り評価しました。12組すべてが1/2であり、長い混在文では文脈による逆向きの選び分けを学べていません。単に訓練を長くするだけでは解決しないことを示す記録です。次は候補表記と文脈の相互作用、特徴量の境界・尺度を訓練専用の対比で検証します。固定評価を狙う個別ルールは追加しません。

```powershell
cargo run --release -p luqnexa-ml --features trainer --bin pair-audit -- MODEL.lqml DATA.jsonl
```

このツールはモデルを変更せず、ペアごとのスコアとSHA-256を表示します。正解候補を与えた順位比較であり、通常変換90%・誤字80%・5msの達成証明ではありません。予定タスク・Qwen・外部APIは起動していません。
