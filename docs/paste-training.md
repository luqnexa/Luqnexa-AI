# ChatGPTの回答を貼り付けて学習

サイトの「ChatGPTの教材を貼る」を開き、教材生成用プロンプトをコピーしてChatGPTへ送ります。JSON回答を入力欄に貼り付けると、検査と端末内学習が自動で始まります。手入力の場合は「検査して学習する」を押します。6分野同数の6〜24問、JSONコードブロックも受け付けます。

ローマ字の実際の読み、正答の大文字小文字、重複、評価専用問題、形式と件数を検査します。JSONはデータとして扱い、含まれるコード・命令を実行しません。意味の正しさ・自然な語彙までは独立して保証できないので、教材は画面で確認してください。

累積教材は最大240例で、固定の調整・評価例は学習に混ぜません。Qwenや外部APIは使わず、保存・訓練は端末内です。結果は候補比較のスコアであり実IME全体の変換精度とは別です。モデルはSHA-256と再現性を確認して保存し、稼働中IMEへ適用しません。学習プロセスは共通ファイルロックで重複実行を防ぎます。競合・失敗の場合はエラーを表示します。

成果物: `.cache/manual-training/runs/`、状態: `.cache/manual-training/status.json`。`lessons.jsonl`は今回教材、`cumulative.jsonl`は過去教材を含む学習専用データ、`model/report.json`は学習と評価結果です。

テスト: `python scripts/test-import-chatgpt-lessons.py`、`python scripts/test-learning-dashboard.py`。実ブラウザーでサンプル6問の貼り付けから学習完了まで検証しました。

完全自動化は公式APIで教材JSONを生成してこの取り込み処理へ渡す方法があります。APIキー・料金・送信先の設定が必要で、現段階では接続していません。現在の貼り付け方式にはAPIキーは不要です。
