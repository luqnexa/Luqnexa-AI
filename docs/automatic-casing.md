# AIによる大文字・小文字の選択

2026-10-11のユーザーの依頼により、入力時の大文字小文字を固定する方式から、端末内Qwenモデルが候補の表記を選ぶ方式へ変更しました。名前や数字の置換・削除・追加は引き続き禁止し、英字のケース変更を許可します。

日本語モードで `chatgpt`、`vscode`、`github` などを入力し、Spaceで変換すると、通常候補に加えて `ChatGPT`、`VSCode`、`GitHub` などの表記候補を作ります。端末内AIが直前の確定文から候補を選び、第一候補を変更します。推論中も通常候補の選択・確定が可能です。文字を入力している途中で確定文を変更する機能ではありません。Enterによる確定はユーザーが行います。

製品名の候補は手書きの固有名詞辞書から取得します。小文字・全大文字・語頭大文字の候補も用意します。元の表記を残し、モデルの応答は候補番号だけに限定します。候補の上限内で最初の3候補から表記違いを追加するため、候補枠が埋まっている入力や未知の複雑な製品表記には対応できない場合があります。すべての固有名詞を収録したものではありません。

モデルは通常文では正式な製品表記、英文中の一般語では小文字、文頭では語頭大文字を選ぶよう指示しています。コードの識別子や正確な引用を文脈で明示した場合は、その表記を維持するよう指示しています。ただし完全な識別や精度は保証しません。URL・パス・メールアドレス・アンダースコアを含む識別子などには表記違いを生成しません。F10で原文入力、F9でAIの無効化が可能です。

英語モードでSpaceを押す操作は従来どおり原文と空白を確定します。ケースAIは明示的な変換イベントで動きます。Windowsで今回の機能を試すときは日本語モードのSpace変換を使用してください。直前の確定文がない場合でも、英語のケース候補があれば一般的な表記を選択します。モデル停止時やタイムアウト時は通常候補で継続します。

入力の外部送信はありません。モデルの起動方法とプライバシーは [端末内AI](local-llm.md) を参照してください。モデル設定はセッション開始時に読み込むため、モデル再起動・IME更新後は入力先アプリを開き直してください。

変更ファイルは `crates/nextime-ai/src/casing.rs`、`local.rs`、`lib.rs`、`crates/nextime-core/src/session.rs`、`tests/end_to_end.rs`、`scripts/local-ai-server.py`、`scripts/test-local-ai.py`、READMEと本書です。モデル本体の再学習ではなく、候補生成・入力検証・モデル指示の変更です。

実モデルのケース選択8件中8件が成功しました（製品名5件、英文の一般語、文頭、コード識別子）。推論は2.594〜4.797秒、中央値3.031秒でした。人工例文の結果であり一般的な精度の保証ではありません。単純な語頭大文字化でできる `Chatgpt`・`Github` などは、既知の製品名の新規候補として生成しません。元の入力がその表記だった場合は保持します。

Rustと実モデルの接続テスト3件も成功しました（文脈による日本語選択、日英混在、ケース選択）。結果は `benchmarks/results/local-llm-casing-curated.json`。途中の失敗結果も別のJSONに保存してあり、全件成功として扱っていません。通常のRustテスト、fmt、Clippy、release build、Python境界テスト、Windowsホスト、既存の日本語回帰テストを確認しました。Windowsホストの100回ウォームアップ後1000回はp50 1.1027ms / p95 2.1023ms / 最大3.2005msです。描画・AI推論は含まず、約128万エントリの辞書を使ったPCでの測定です。1億エントリやiPhone SEでの測定ではありません。

Windowsへの反映はUAC確認が取り消されたため未適用です。現行の登録先は `C:/Program Files/NextIME/build-cb001dbf6e98a14a` のままです。新ビルドは `C:/opencode-rust/target/windows-x64` に保存しました。端末内のAIヘルパーは新しいモデル指示で稼働していますが、新しいケース候補生成にはIME DLLの更新が必要です。

更新する場合は管理者のPowerShellで以下を実行し、その後入力先アプリを開き直してください。

```powershell
./scripts/update-windows.ps1 -ArtifactDirectory C:/opencode-rust/target/windows-x64
```
