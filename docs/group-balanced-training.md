# 文章と文脈ごとの学習量をそろえる実験

2026-10-13。累積118対比は98組の入力・文脈で構成されています。誤候補を追加した組は最大3対比あり、全対比を毎epoch学習すると、その文章は対比1件の文章より最大3倍の更新を受けていました。教材が増えたことと、場面の多様性が増えたことは同じではありません。

Rust学習CLIへ明示的な `--schedule grouped-shuffled` を追加しました。trainの入力・文脈で組を作り、各epochで各組を一度だけ選びます。複数の誤候補はepochごとに順番を回し、組の順序だけseedから再現可能にシャッフルします。同じ入力でも文脈が違う組は別です。組の作成は出現順で決まり、HashMapの反復順に依存しません。validation/testは組に含めません。最大3対比の組は3epochで全対比を使います。分野や語彙の意味的な偏りまで自動で解決する仕組みではありません。

既定のcyclicと従来のshuffledは維持します。報告へ組数、最大対比数、更新回数、実際のepochカバー範囲を追加しました。新方式の更新は2,000epoch×98組＝196,000回で、全対比方式の236,000回とは異なります。同一更新回数を使う比較ではありません。

同じ累積118対比・データSHA-256 `f3dce77f8f7a1cbc98f5e84641f01b7749b223250393cf136091666d1d0c8eb4`、interaction-v2、seed1337、2,000epoch、減衰0で独立二度実行しました。モデル選択はvalidationのみ、testは選択後に記録します。固定評価内容を変更せず、評価の個別解答に合わせた教材や重みの調整はしていません。

新モデルSHA-256は両方 `d68e690804bed92b50b98ce714de7aea06845298446c19b7eb8bff69540bc85f`。旧shuffledを追加実装後に再実行したSHA-256も変更前の `3000de308c2209d5d92ec826b1f55f603bfa82f5bd956969e954f496a27e1b3e` と一致しました。推論形式・モデルサイズ・推論コードは変更していません。

候補比較のtest増加を一般精度の改善やモデル採用の根拠には使いません。validationは旧研究モデルの10/12を下回っています。実辞書の固定validationでは新モデルを使う既存候補生成経路は2/12、統計接続経路は7/12・候補内10/12・Windowsウォームp95は53.33msでした。旧研究モデルはそれぞれ4/12、7/12なので、新モデルは不採用として保存します。稼働IMEへ適用しません。

同じ教材でも学習方式を変えた実験であり、新しい文章の追加ではありません。自己点検された小さな固定評価を繰り返し使っており、独立した人間の未知文評価ではありません。90%・5ms・誤字80%は未達です。予定タスク、Qwen、外部推論API、個人履歴は利用しません。

```powershell
cargo run --release -p luqnexa-ml --features trainer --bin luqnexa-train -- --data DATA.jsonl --output NEW-RUN --epochs 2000 --seed 1337 --architecture interaction-v2 --schedule grouped-shuffled
```

単体テストは毎epochの組の均等回数・全誤候補の巡回・seedの再現性・別文脈の分離を確認します。CLIテストは評価用行が組に入らないこと、報告の組数・更新回数、旧成果物を上書きしないことを確認します。
