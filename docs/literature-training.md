## 作品と処理

日本語：吾輩は猫である、こころ、坊っちゃん、羅生門、鼻、杜子春、蜘蛛の糸、人間失格、走れメロス、銀河鉄道の夜、注文の多い料理店、山月記、舞姫、高瀬舟、たけくらべ。各版の作品IDと正式な出典は学習JSONを参照してください。検証用は人間失格・高瀬舟、テスト用はこころ・たけくらべで、これらは文学モデルの学習には使用しません。

英語：Pride and Prejudice、Sense and Sensibility、Emma、A Christmas Carolが学習用。Great Expectationsは検証用、Alice’s Adventures in Wonderlandはテスト用です。

日本語の学習片13,082、英語24,911。検証・テストも含めた重複なしの取得片は合計56,126です。文境界は句読点による簡易分割で、長い文は160文字以下の片に分けます。4文字未満の片は使いません。文の切れ目、英語略語、旧かな・旧漢字、外字などを完全に解析する処理ではありません。

ルビ・注記・見出し・底本等の末尾情報を学習本文から除き、空白を正規化します。由来の情報はJSONに別途保持します。表記の現代化や事実修正は行いません。作品ごとの分割後、評価用から優先して文章片を重複排除し、同一の文章片を複数の分割先に入れません。他の既存コーパスとの重複まで排除した評価ではありません。

生の特徴257,850から、頻度3以上・頻度上位最大200,000の条件で57,994特徴を採用しました。追加モデルは927,912バイト（約0.885MiB）、SHA-256は `6627a44432c4cca6d45afb247eb460d00f5c9b5d1ccd9dfe7fd01c4de4c9ad9d`。組み込みモデル全体は191,989特徴です。原文をIME起動時に読むことはありません。

文学モデルの補正は8分の1の重み、最大256点、3文字以上の候補のみです。実辞書の試験で、文学の頻度が短い語のかな候補を押し上げる問題を検出し、短い同音語は従来の文脈・選択学習で評価するように調整しました。英語モードの予測候補にも組み込みAIの評価を接続しています。古典文学は現代のチャット・スラングを代表するデータではありません。

## 再実行・検証

```sh
python -X utf8 scripts/train-literature.py --download
python -X utf8 scripts/test-train-literature.py
cargo test --workspace --locked
cargo bench -p nextime-core --bench context --locked
```

取得は固定の許可リストに限定します。`--download` は不足しているキャッシュだけを取得し、既存のキャッシュを上書きしません。標準ではキャッシュを使います。Standard Ebooksは公式リポジトリのキャッシュ、または公式OPF・ライセンス・本文をまとめたファイルを使い、不要な大量画像を取りません。ZIPを作業ディレクトリに展開せず、必要なファイルだけ読みます。

同じキャッシュで同じバイナリを再構築できます。配布元は更新されるため、別端末での再取得が同じスナップショットになる保証はありません。出典ハッシュで確認してください。原文キャッシュは `.cache/literature` に保持しGit対象外、モデルと出典・評価JSONはリポジトリ対象です。通常のIME入力・CIが原文をダウンロードする処理はありません。
