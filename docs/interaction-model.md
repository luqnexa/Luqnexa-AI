# 文脈と候補表記の相互作用モデル

2026-10-13。通常変換90%以上・変換全体p95が5ms以内・誤字補正80%以上を継続目標とします。今回の変更は、文脈の異なる対比を学べない原因に対するRustの研究実装です。

従来の48次元（読み16・文脈16・候補16）のうち、文脈チャネルを文脈埋め込みと候補埋め込みの要素ごとの積へ置き換えます。積を埋め込み次元数16でスケールします。入力次元・隠れ32ユニット・重み数・ファイルサイズは増やしません。積の両入力へ勾配を戻し、数値微分との一致を検査しました。一般言語理解を完成させたものではありません。

新形式は`LQML0002`。既存`LQML0001`は従来のスコア計算とバイト列を保持して読み書きします。未知のバージョンは拒否します。`Trainer::new`と学習CLIの既定は従来形式で、新方式は`Trainer::new_interaction`または`--architecture interaction-v2`で明示的に選びます。既定モデルや稼働IMEへ未検証の研究モデルを適用しません。

```powershell
cargo run --release -p luqnexa-ml --features trainer --bin luqnexa-train -- --data DATA.jsonl --output NEW-RUN --epochs 2000 --seed 1337 --architecture interaction-v2
```
